## 2. 设备标识（imei 字段）

App 在 4.4.x 已不使用真实 IMEI，而是：

```java
// MyPhone.getImei()
String id = "TS" + MD5Util.stringToMD5_short(uniqueId).toUpperCase();
```

即 `"TS"` + 16 位大写十六进制，共 18 字符，例：`TS91A8CF8706D645F5`。
PC 端移植时用「安装时生成的随机 UUID」做种子，保持全局稳定即可。

### 3.2 节点表加密

`serverlist_encrypt.json` 内容是一整段**大写十六进制字符串**（无换行），解密参数：

```
算法：DES / ECB / PKCS5Padding
密钥：dw!@#$%^          （8 字节，来自 libGSCore.so Jni.e()，即 "dw!@#$%^" 的 hex 反转再反转）
密文：hex 解码后的字节
明文：UTF-8 文本的 JSON 数组（596 条）
```

> `Jni.e()` 返回 `hex("dw!@#$%^")` 反转后的字符串，Java 侧 `DesUtil.constDecrypt()` 再反转+hex 解码得到密钥。
> 静态字符串 `dw!@#$%^` 直接可见于 `libGSCore.so` `.rodata` 0xd90b3。

节点对象字段：

```json
{"cityid":"48002001","geoid":"48002","hostid":"5","hostip":"124.74.52.254",
 "hostname":"上海电信","location":"上海","oper":"电信","pname":"上海","port":"65499"}
```

## 5. 测速会话（核心）

### 5.1 建立会话

```
GET http://<hostip>:<port>/speed/dovalid
    ?key=                        // 首次为空
    &flag=true                   // true=开始；false=其它
    &bandwidth=<签约带宽Mbps整数>  // 移动网 200/300/150，WiFi 默认 50…（见 §7）
    &model=Android
    &imei=<TS..>
    &time=<Unix秒>
    &app=<包名末段>               // globalspeed
    &token=<32位小写MD5>
    &pkg=com.cnspeedtest.globalspeed
```

**token 算法（逆向自 libGSCore.so `Jni.b()` + 实网校验通过）：**

```
b1 = "model=" + model + "&imei=" + imei
b2 = "stime=" + time  + "&band=" + bandwidth + "&rand=12345555"
token = md5_hex( md5_hex(b1) + md5_hex(b2) )      // 全小写
```

Python 参考实现：

```python
def token(model, imei, t, bw):
    b1 = f"model={model}&imei={imei}"
    b2 = f"stime={t}&band={bw}&rand=12345555"
    return md5(md5(b1) + md5(b2))
```

响应：

```
1-<uuid>       成功，uuid 从第 3 个字符起（Java：reply.substring(2)）
0...           服务器拒绝
2...           服务器忙/等待
-1-            参数错误（token/imei 校验失败，或节点不可用）
```

> 实测：`1-2d94f550-447a-4b7e-9b9d-09399999b949` → key=`2d94f550-...`

### 5.2 下行测速

```
GET http://<hostip>:<port>/speed/File(1G).dl?r=<Unix秒>&key=<uuid> HTTP/1.1
Accept: */*
Connection: close
User-Agent: Mozilla/5.0 (Windows NT 10.0; WOW64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/100.0.4896.60 Safari/537.36
Host: <hostip>:<port>
```

- 原始 socket 读取，**不解析 chunked**，只累加 `recv()` 字节数
- 首个分组里用 `\r\n\r\n` 定位响应头，`Content-Length`/状态码仅用于判定
- 默认 8 个并发连接（`down_thread`），每连接 64KB 缓冲

### 5.3 上行测速

```
POST http://<hostip>:<port>/speed/doAnalsLoad.do HTTP/1.1
Connection: close
Cache-Control: no-cache
Charset: UTF-8
Key: <uuid>
Content-Type: multipart/form-data;boundary=00content0boundary00
User-Agent: Dalvik/1.6.0 (Linux; U; Android 4.2.2; GT-I9505 Build/JDQ39)
Host: <hostip>:<port>
Accept-Encoding: gzip
Content-Length: 900000000

--00content0boundary00
Content-Disposition: form-data; name="upload";filename="SPEED_20260101_000000_000"

<此后无限写入 16KB 随机字节>
```

- `Content-Length` 恒为 900000000，实际写到采样结束就 `close()`
- 服务器最终返回 `200 Content-Length: 0`
- 默认 4 个并发连接（`up_thread`）

### 5.4 结束会话

```
POST http://<hostip>:<port>/speed/dovalid?key=<uuid>     // body 空
→ 200，body 回显 1-<uuid>
```

## 6. 采样与统计

`SpeedParams`：`interval=500ms`、`length=8s`（→ `points=16`）、`preheat=2000ms`（→ `preheat_points=4`）。

`Sampler` 每 500ms 取一次「累计传输字节增量」：

```
speed_mbps = deltaBytes * 8 / interval / 1e6                          // 首个采样点（0.5s 窗）
speed_mbps = (lastDelta + deltaBytes) * 8 / (interval*2) / 1e6       // 之后（1s 滑动窗）
```

> ⚠️ **实现陷阱**：`interval*2` 的单位是**毫秒**，`calcSpeed_Mbps(bytes, millis)` 内部是
> `bytes * 8 * 1000 / millis / 1e6`，即 1 秒窗时为 `bytes * 8 / 1e6`。
> 移植时若写成 `(sum)*8/2/1e6`（把 2 当成"2 秒"而不是"2000 毫秒"），结果会**恒定只有真实值的一半**。
> PC 版初版即踩此坑（显示 190 Mbps，任务管理器实测 397 Mbps，正好 2 倍），已改为
> 「真实时间戳的 1 秒滑动窗口」：`speed = (total - total_at(t-1s)) * 8 / span / 1e6`。

- 前 4 个点标记为「预热」，不进入统计，但会推送给 UI 画曲线（如果开启）
- 之后每个点 `addSpeed()`

`Throughtput`：

```
max  = max(samples)
avg  = Android < 15 : 排序后取最大的 3 个点的均值
       Android >= 15: 全部采样点均值
```
> PC 端采用「全部采样点均值」（对齐 Android 15+ 行为），并同时给出峰值。

`PingTask`：优先调用系统 `ping -s <size> -c <count> -W <timeout>`，解析输出得 avg/jitter/loss；
若 ICMP 不可用则退化为 **TCP 握手 RTT**（`MyPingHelper.do_tcpping`，连服务器端口，取 N 次均值）。

## 7. 线程数与带宽档位

`SpeedTestTask.setThreadCount()`：

| network_class | 含义 | down_thread | up_thread |
|---|---|---|---|
| 4 | 4G | 10 | 4 |
| 5 | 5G | 16 | 6 |
| 9 | WiFi | 8 | 4 |
| 其它 | 默认 | 8 | 4 |

`setMobileBandwidth()`：移动网 `bandwidth=200`（class 9）/ `300`（某些类型）/ 默认 `150`；WiFi 默认 `50`。

> 这些值只影响会话声明，不影响实际吞吐。PC 端默认 8/4 线程，可在设置里改。
