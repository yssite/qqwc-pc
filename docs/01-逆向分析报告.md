# 全球网测 Android v4.4.8 逆向分析报告

> 样本：`全球网测_v4.4.8.apk`（9,229,480 B，包名 `com.cnspeedtest.globalspeed`，versionCode 40408）
> 出品：中国信息通信研究院（CAICT）泰尔终端实验室；底层引擎为「鼎利 DataTest SDK」定制版
> 分析环境：Windows + JDK17 + jadx 1.5.1 + apktool 2.11.1 + Ghidra 12.2 + Frida 16.1.11 + Android 16 x86_64 模拟器（ARM 翻译）

## 2. 脱壳

### 2.1 静态结论

- `classes.dex` 的 `map_list` 只覆盖到 0x3d88，之后 3.4MB 不属于任何 dex 段 → 是**外部载荷**。
- 载荷并非整段 AES，而是「指令抽取 + 字符串加密」：0x140000 之后可看到合法 dalvik 操作码（`6e10`=invoke-virtual）与乱码交错。
- 载荷内没有明文类名，静态还原需要还原壳的 VM，成本过高 → 转动态。

### 2.2 动态脱壳（自建方法）

1. 新建独立 AVD（API 36，x86_64，`google_apis`），`adb root`。
2. 实测该镜像带 **ARM 翻译**（`ro.enable.native.bridge.exec=1`，`abilist=x86_64,arm64-v8a`），arm64 动态库可跑（**静态链接的 arm64 可执行文件会段错误，必须动态链接**）。
3. 安装 APK → `monkey` 拉起 → 得到 pid。
4. 自写 arm64 注入式内存扫描器 `dexmem`（NDK 交叉编译，`/proc/<pid>/maps` + `/proc/<pid>/mem`），按 `dex\n03x` 魔数 + `endian_tag=0x12345678` + 合法 `file_size` 过滤，落盘 72 个 dex 镜像（95MB）。
5. 其中 `d000`（6,316,840 B，dex 037）含 **5,529 个类**，`Lcom/ruili/` 出现 485 次 —— 即主 dex。

成功率验证：jadx 处理 1,720 个类，仅 8 个失败（`invoke-custom`/壳内特殊结构），2,576 个 `.java` 落地。

> 注：`MainActivity.onCreate` 等少量方法仍是 `native`（壳的 native 化抽取），这部分用「行为观测 + 协议抓包」补齐，不影响业务逻辑还原。

## 4. native 层（libGSCore.so）

### 4.1 基本面

- ELF64 aarch64，`.text` 0x3fa90 起，621KB，**仅导出 `JNI_OnLoad/JNI_OnUnload`**，其余全部去符号。
- 依赖：libcurl、libssl/libcrypto(1.1.0)、libz、liblog。
- Ghidra 识别 2,345 个函数，成功反编译 1,676 个。

### 4.3 内嵌 VSP 引擎

`.rodata` 出现完整脚本引擎痕迹：

```
vsp_init / vsp_parse / vsp_uninit / vsp_version ("20210709.1")
text_operation / http_request / final_result / share_variables
markResultInfo / markResultUrl / url_contains_domain / random_uuid / is_fail
AesDecrypt Fail / UnzipData Fail / GetVideoJson Fail / SetShareVariables Fail
${variables.xxx} / Error Format ${variables.xxx}
"code": "message": "quality": "url": "headlist":
```

即：**测速/视频/网页等上层业务由「加密+压缩的 JSON 脚本」描述**，文件头 `AesDecrypt` + `Unzip` 后交给 VSP 解释执行，动作类型包括 `text_operation`、`http_request`（走 libcurl，UA 伪装 Chrome 137）等。
脚本来源：`https://dlcv2.cnspeedtest.com:8043`（配置 CDN），本地缓存 `/tmp/vsp_job.log`。

> 这是本 App 的「可配置业务层」：新增测试站点/视频平台无需发版，只下发脚本。
> PC 移植版不复刻 VSP，直接把「接入网测速」用原生 Rust 实现（这是 99% 用户真正要的功能）。

## 5. 关键算法

### 5.1 会话 token（已实网验证）

```java
// SpeedTestTask.enqueue()
String t  = "" + (System.currentTimeMillis()/1000);
Jni.b(String.format("%s,%s,%s,%s,%d,%s", "", imei, "Android", t, bandwidth, appName));
```

逆向自 `Jni.b` → `FUN_00177e44`（按 `,` 分割 → 要求 ≥5 段 → 两次 MD5 拼接）：

```
b1 = "model=" + model + "&imei=" + imei
b2 = "stime=" + time  + "&band=" + bandwidth + "&rand=12345555"
token = md5_hex(md5_hex(b1) + md5_hex(b2))
```

Ghidra 片段可对照：常量 `"model"`、`"imei"`、`"stime"`、`"band"`(`0x646e6162`)、`"rand"`(`0x646e6172`)、盐 `"12345555"`(`0x3535353534333231`)、分隔 `","`/`"&"`。

### 5.2 平均速率

```java
// Throughtput.getAvgSpeed()
sort(samples);
int n = (SDK >= 35) ? samples.size() : 3;   // Android 15+ 改为全量平均
avg = mean(last n samples);
```
PC 端取「全量平均 + 峰值」双指标，和 Android 15+ 行为一致。

### 5.3 采样

`interval=500ms`，`length=8s`，`preheat=2s(4 点)`；速度为 1 秒滑动窗口字节增量换算 Mbps。

### 5.4 节点表密钥

`Jni.e()` = `reverse(hex("dw!@#$%^"))`，`DesUtil.constDecrypt` 再反转 + hex 解码 → 密钥 `dw!@#$%^`，
DES/ECB/PKCS5 解 `serverlist_encrypt.json`（hex 文本）→ 596 节点 JSON。

## 9. 移植决策

| 原实现 | PC 方案 |
|---|---|
| jiagu 壳 + Java 业务层 | 不移植，重写 |
| VSP 脚本引擎（视频/网页模板） | 不复刻；「接入网测速」原生实现，「网页/文件/Ping/DNS/Traceroute」用 Rust 直接写 |
| libcurl + 原始 socket 混用 | 统一 `std::net::TcpStream` + 轻量 HTTP 客户端（避免依赖重量级 TLS 栈测速） |
| 系统 `ping` 命令 | Windows ICMP（`IcmpSendEcho`）+ 降级 TCP 握手 RTT |
| Room/自研 ORM | JSON 文件（`app_data/history.json`） |
| Tauri 2（Rust）+ WebView2 + 原生 Canvas UI | 见 `docs/03-架构设计.md` |

> 遗留：`resultEvaluation.php` 的评价文案、`video_rules.dat` 的流解析规则未复刻，PC 版用本地规则做评级。
